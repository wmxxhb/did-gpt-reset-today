# GPT今天重置了吗？

在手机微信里接收 Tibo（[@thsottiaux](https://x.com/thsottiaux)）的额度重置预告、发放进度和完成通知。当前关注 Codex / ChatGPT Work 的全局额度公告。

通过 Windows 中文向导部署到 Cloudflare，电脑关机后监控仍在云端运行。

默认使用微信服务号接收通知，也可以扫码开启 **ClawBot 聊天提醒**。主菜单 2 可选择测试服务号、ClawBot 或两个通道；主菜单 8 用于管理聊天绑定。

**[下载源码 ZIP](https://github.com/wmxxhb/did-gpt-reset-today/archive/refs/heads/main.zip)** → 解压 → 双击 `打开工具.cmd`。

## 功能

- 中文编号菜单：开通、连接已有工具、检查状态、测试通知、暂停和恢复。
- 自动识别部署地址、加密保存本机管理凭据，不用手工拼测试命令。
- 预告和完成分阶段提醒，可选择仅完成或全部进度，可储备重置独立开关。
- 动态等待标识、已用时间、网络超时与直接重试。
- Windows 系统代理和证书支持，避免浏览器能联网、向导却连接超时的问题。
- 持久化去重、失败重试，测试通知由用户明确确认是否收到。
- 可选的微信 ClawBot 聊天提醒：扫码绑定，与服务号同时推送，独立记录会话状态和失败重试。

## 从这里开始

**双击 `打开工具.cmd`，输入菜单编号。** 不需要自己拼网址、复制测试命令或逐项上传配置。

第一次打开会自动准备依赖。需要 Node.js 22 或更新版本；若没有，入口会提示打开官方下载页安装。已有 Codex 的机器会尝试使用它自带的运行组件。安装后重新双击入口即可。

- **第一次使用**：选择“第一次使用：开通微信提醒”。
- **已经开通**：选择自动接管，或输入原网址与管理密钥导入。
- **再次打开**：直接进入管理菜单，管理凭据由当前 Windows 账号加密保存。

联网、保存配置、登录授权和部署时，会显示动态等待标识与已等待秒数。云端管理请求约 30 秒超时返回；浏览器授权过程则持续显示“等待授权”，不会显示虚假的完成百分比。连接失败后可直接重试，本次输入的密钥仍保留在内存中，无需重复粘贴。

Windows 版连接云端使用系统网络组件，沿用 Windows 系统代理与证书设置。若系统代理已启用，请保持代理程序运行。超时、域名解析失败、证书错误和密钥不匹配会分别显示对应提示；不会一概提示等待 DNS。

自动接管会更新程序并生成新的管理凭据，原管理密钥将失效；微信绑定、监控记录和提醒偏好会保留。向导会先说明并让你选择，退出不会执行接管。

## 更新已安装的工具

更新包含本机向导和云端程序两步：

1. 关闭正在运行的工具窗口。如果使用 Git 克隆，在原仓库目录执行 `git pull --ff-only`；如果使用 ZIP，重新[下载源码](https://github.com/wmxxhb/did-gpt-reset-today/archive/refs/heads/main.zip)，完整解压后，将其中的源码文件复制到原工具文件夹并覆盖，**保留原有 `.tibo-local` 配置目录**。
2. 重新双击原文件夹的 `打开工具.cmd`，新增运行组件会自动准备。
3. 进入主菜单，选择 **6「更新云端程序（保留绑定）」**。
4. 选择 **2「发送测试通知（选择通道）」**，验证需要使用的通道。

菜单 6 更新的是云端程序，不会下载新版的本机向导。如果看不到菜单 8 或测试通道选择，请先完成第 1、2 步。使用同一 Windows 账号并保留本机配置时，无需重新输入管理密钥；如果换了文件夹或电脑，可以从欢迎菜单连接已有实例。

## 首次开通需要准备什么

1. [Cloudflare 账号](https://dash.cloudflare.com/)，用于运行云端定时任务；本项目配置可使用 Free 计划。
2. 用微信关注[虾推啥公众号](https://xtuis.cn/)，取得 token。使用免费微信通道，官网目前列出的流程没有付费实名步骤。向导也兼容已有 pushplus 账号，但它可能需要付费实名。
3. 联系邮箱或项目 HTTPS 地址：公开数据接口要求用它标识请求者。

向导会依次引导选择提醒内容、登录 Cloudflare、部署、保存绑定、检查状态并发送测试通知。最后需要明确选择“已收到 / 没收到 / 稍后验证”。只有你选择“已收到”，状态页才会记录微信验证完成。

Cloudflare 首次开通免费网址时可能仍出现英文提示：是否创建选 `yes`，名称可以填 `tibo-alert-加任意数字`，最后确认选 `yes`。这个名称只是免费网址的一部分，不需要购买域名。向导会自动读取最后部署的完整工具地址。

## 可以选择哪些提醒

| 选项 | 收到的内容 |
| --- | --- |
| 预告 + 完成（推荐） | 出现明确预告时提醒，完成声明或监测站完成记录出现时再提醒 |
| 仅提醒完成 | 跳过预告和发放过程，只关注完成信息 |
| 全部进度 | 预告、正在发放、完成 |

可储备重置（banked reset）单独开关，推荐默认关闭。这类重置通常需要手动使用，不能当成自动恢复额度。

现有实例升级后保留原有提醒范围；只有你从菜单保存新选项时才改变。切换选项不会补发此前跳过的历史消息，也会清理队列中已不需要的提醒。

## 日常管理

再次双击入口，可以选择：

- 查看运行状态：正常、暂停、等待初始化或需要排查。
- 发送测试通知：选择仅服务号、仅 ClawBot 或分别测试两个通道，每个通道分别确认收到。
- 修改提醒内容。
- 暂停或恢复提醒。
- 更换服务号微信绑定，之后重新验证送达。
- 更新云端程序，保留微信绑定。
- 重新接管管理权限。

关闭窗口或电脑关机不会停止已部署的云端监控。只有从菜单选择暂停才停止提醒。

管理凭据保存在 `.tibo-local/profile.dat`，使用 Windows DPAPI 绑定当前系统用户加密。请勿共享 `.tibo-local` 目录；换电脑或系统用户后，可以重新接管。微信推送 token 上传到 Cloudflare Secrets，向导不会将它明文写入项目文件。

## 发送测试通知

主菜单选择 **2「发送测试通知（选择通道）」**：

| 选择 | 发送位置 | 确认方式 |
| --- | --- | --- |
| 仅测试服务号 | 已绑定的虾推啥或 pushplus 服务号 | 在服务号中查看并确认 |
| 仅测试 ClawBot 聊天提醒 | 已绑定的微信 ClawBot 会话 | 在 ClawBot 会话中查看并确认提醒效果 |
| 分别测试服务号和 ClawBot | 先服务号，再 ClawBot | 分别回答是否收到，单个通道失败不影响另一个通道测试 |

首次开通和更换服务号绑定后的自动测试只验证服务号。ClawBot 需要先在菜单 8 扫码开启；聊天测试前会自动同步你发给机器人的回复。每个通道每分钟最多测试一次，聊天测试也计入会话发送额度。

只收到服务号测试时，请检查选择的测试通道。若已选择 ClawBot，先向微信里的 ClawBot 发一句话，再重试；如提示需要登录，从菜单 8 重新扫码。测试过程中选择「没收到 / 稍后检查」不会记录为已送达。

## 可选：微信聊天提醒（ClawBot）

希望在微信聊天会话中接收通知，可以从主菜单选择 **8「微信聊天提醒（ClawBot，可选）」**。此通道默认关闭，开启后与服务号同时发送，可能收到两份提醒。无需备用微信号、常开电脑或额外部署项目。

1. 旧版本先选择主菜单 **6「更新云端程序（保留绑定）」**。
2. 进入菜单 8，选择「扫码开启 / 更换聊天绑定」。
3. 用接收通知的手机微信扫描终端二维码，确认授权；若手机显示配对数字，按向导输入。
4. 在微信 ClawBot 会话中主动发送一句话，例如「开启提醒」。
5. 回到向导选择「已发送，激活并测试」，在手机上检查声音、锁屏提示和未读标记，再确认测试结果。

这是基于微信 iLink 的实验性可选通道。**最后一次用户消息之后约 24 小时、连续约 10 条消息后，需要你再回复一句话。** 工具约每两分钟同步回复，也可从菜单手动刷新。显示的剩余额度是本工具的保守估计，测试及可能已经送达的超时请求也会占用估计额度，微信实际限制为准。机器人自行发消息不能延长会话。

聊天发送失败不会阻塞服务号，也不会重新发送已成功的服务号消息。聊天通知最多排队一小时，过期自动丢弃；回复后可以补发尚未过期的消息。暂停提醒和修改提醒范围对两个通道都生效。关闭并清除聊天绑定会删除该通道的凭据和待发消息，服务号继续运行；重新开启不会补发关闭期间的通知。

微信是否允许账号绑定，以及声音、角标和锁屏表现，以你的微信版本、系统设置和实际测试为准。接口接受仅表示请求被接受，不代表手机送达。主菜单 2「发送测试通知（选择通道）」支持选择服务号、ClawBot 或两个通道；每个通道分别确认，单个通道失败不会阻止另一个通道测试。聊天测试前会自动同步你刚发给 ClawBot 的回复。主菜单 5「更换服务号微信绑定」用于服务号；聊天通道的测试、更换和关闭也可在菜单 8 内操作。

实现参考：[腾讯 iLink 接入项目](https://github.com/Tencent/openclaw-weixin)、[Cloudflare 通知桥接方案](https://github.com/krapnikkk/Cloudflare-WeChat-Notifier)、[会话限制说明](https://github.com/yuuouu/WeChat-Bridge#微信侧限制)。本项目直接在现有 Worker 中接入 iLink，不依赖上述社区桥接服务的托管实例。

## 数据与可靠性

每两分钟读取一次独立社区站 [codex-reset.com](https://codex-reset.com/developers/) 的公开数据，包含它采集的 Tibo（@thsottiaux）帖子和回复。并非直接连接 X，也不能保证完整收录。叠加源站采集、云端检查和微信投递，可能有数分钟延迟。

预告、正在发放、Tibo 完成声明、第三方监测记录会使用不同标题。通知包含原文、原帖链接、发布时间和来源。原帖的 today/tomorrow 按作者当地语境理解，不会自动当作北京时间今天。工具没有连接你的 GPT 账号，不能直接确认个人额度到账。

首次启动静默建立基线。之后补收最近 72 小时内的新事件；同一事件从预告升级为完成仍会提醒。失败会保留队列并退避重试；普通成功情况下按事件 ID 和阶段去重。网络超时或异常中断时仍可能重复发送。

推送服务返回 HTTP 成功只表示它接受了请求；实际送达以手机为准。无流水号时不会编造回执。工具没有独立于微信的故障通知通道，数据源或微信服务中断时，需在菜单中查看状态。

虾推啥当前免费微信通道每日 300 条、每分钟 30 条，卡片显示简短标题，完整正文在详情页/小程序中查看，正文约保留三天。规则与免费额度可能变化，不保证永久免费或每条必达。

## 开发与高级操作

普通用户无需执行下面的命令。开发时使用 Node.js 22+：

```powershell
npm ci
npm test
npm run check:public
npm run manage
npm run preview
npm run dev
```

也可以使用 `npm run setup` 或 `启动部署.ps1` 启动向导。开发预览不发送微信消息。本地 Worker 配置参见 `.dev.vars.example`。

管理 API 包括 `/status`、`/test`、`/check`、`/pause`、`/resume`、`/settings`（GET/POST）和测试确认接口，均需要 `Authorization: Bearer 管理密钥`。菜单会自动完成这些调用。

聊天 API 包括 `/clawbot/status`（GET），以及 `/clawbot/login/start`、`/clawbot/login/poll`、`/clawbot/refresh`、`/clawbot/test`、`/clawbot/confirm-test`、`/clawbot/disable`（POST），同样需要管理密钥。内部入队和定时投递接口不对外开放。聊天绑定保存在同一 Durable Object 类的独立实例中，无需新增数据库或迁移配置。

发布前请先暂存要提交的文件，再执行 `npm run check:public`。GitHub Actions 在 Windows 和 Linux 上执行测试及公开发布检查，不部署实例、不读取用户密钥，也不发送微信通知。

`wrangler.jsonc` 中的 `tibo-wechat-reset-alert` 是 Cloudflare 服务名，账号子域名由 Cloudflare 账号分配。升级已有实例时请保持服务名不变，以连接原有服务和数据。
