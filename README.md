# GPT今天重置了吗？

查看 Tibo（[@thsottiaux](https://x.com/thsottiaux)）发布的 Codex / ChatGPT Work 额度重置消息，并按需通过微信接收提醒。

**[下载最新版 ZIP](https://github.com/wmxxhb/did-gpt-reset-today/archive/refs/heads/main.zip)** → 完整解压 → 双击 `打开网页版.cmd` 或 `打开工具.cmd`。

## 功能

- 查看重置预告、发放进度、完成声明和第三方监测记录，附发布时间与原帖链接。
- 查看今日重置状态、上次重置时间，以及可按月份浏览的重置日历。
- 可选服务号提醒、ClawBot 聊天提醒、两者同时开启，或只查看动态。
- 自定义提醒范围，选择是否接收可储备重置消息。
- 查看各通道的发送记录，发送测试通知，并分别确认手机是否收到。
- 暂停或恢复通知、更换微信绑定、连接已有工具及恢复管理权限。
- 提供网页和终端两种入口，共用本机配置；开通后电脑关机仍会监控。

## 使用指南

### 准备

需要 Windows、Node.js 22 或更新版本，以及一个 [Cloudflare 账号](https://dash.cloudflare.com/)。启动入口会检查所需组件，缺少时按提示安装。

| 入口 | 使用方式 |
| --- | --- |
| `打开网页版.cmd` | 自动在浏览器打开本机管理页；使用期间保留后台启动窗口 |
| `打开工具.cmd` | 使用终端中文菜单 |

### 首次开通

1. 打开任一入口，选择「开始设置」或「第一次使用，开始设置」。
2. 选择通知方式，仅需配置选中的通道。
3. 按向导登录 Cloudflare，完成云端开通和微信绑定。
4. 发送测试通知，在手机上确认收到后记录结果。两种通道需分别确认。

| 通知方式 | 绑定方法 | 使用特点 |
| --- | --- | --- |
| 服务号 | 关注[虾推啥](https://xtuis.cn/)并填写 token；也支持已有 [pushplus](https://www.pushplus.plus/) 账号 | 维护操作少，微信可能折叠通知 |
| 聊天提醒 | 用接收通知的微信扫描 ClawBot 二维码，再向机器人发一句话 | 在聊天会话中接收，需要定期回复续期 |
| 两种都开启 | 分别绑定两个通道 | 同时发送两份提醒 |
| 只看动态 | 无需绑定通知通道 | 更新动态，不发送通知 |

首次使用 Cloudflare 可能需要注册 workers.dev 免费网址。网页版按提示打开官方页面完成注册，再点击继续；终端若询问是否注册，选 `yes`，填写一个未被使用的子域名，再确认。工具会自动识别完整地址，无需购买域名。

首次成功读取数据时只建立历史记录，不补发旧消息。默认提醒「预告 + 完成」，可储备重置默认关闭。设置中断时，重新打开并选择「继续开通」即可。

### 日常使用

- **概览**：查看「今日暂无重置消息」「今日将会进行重置」或「今日已重置」，上次重置时间单独保留。数据异常时会提示暂时无法确认。
- **重置日历**：在概览中切换月份，点击日期查看该日记录。完成记录与预告使用不同标记；无标记表示暂无记录。
- **最近动态**：查看原帖和各通道的处理结果。
- **通知设置**：绑定、更换或独立开关服务号与聊天提醒，也可以发送测试通知。
- **提醒范围**：网页版在「通知设置」修改；终端在「更多 → 提醒内容」修改。
- **暂停通知**：继续更新动态，但不发送通知；恢复后不补发暂停期间的消息。
- **更多**：检查更新、连接已有工具、恢复管理权限和查看诊断信息。

今日状态和日历按北京时间的消息日期统计。上次重置时间只取完成声明或监测站完成记录，可储备重置不计入。预告尚不代表已完成，明确指向未来日期的预告不会算作发布当天的重置。

关闭通道会保留绑定，重新开启后不补发关闭期间的消息。需要移除聊天凭据时，使用「清除聊天绑定」。关闭管理页面、启动窗口或电脑，不影响云端监控。

### 聊天提醒续期

ClawBot 会话通常在最后一次用户消息后约 24 小时，或连续发送约 10 条消息后，需要你再回复一句话。实际限制以微信为准，机器人自行发消息不会续期。

回复后工具约两分钟内自动同步，也可以在聊天设置中手动刷新。会话过期期间的待发消息最多保留一小时，超时不补发。测试和恢复确认也会占用会话额度。

### 更新与更换电脑

在「更多 → 检查更新」中按提示更新本机文件，关闭网页及后台窗口后重新打开，再按需更新云端。更新会保留已有绑定和提醒设置。

如果无法使用更新入口，可下载新版源码覆盖原文件，**保留原来的 `.tibo-local` 文件夹**。换电脑时选择「连接已有工具」，输入原网址和管理密钥；找不到密钥时可选择「恢复管理权限」，恢复后旧密钥失效，已有云端绑定和记录保留。

### 常见问题

- **聊天提醒要求续期**：在微信给 ClawBot 回复一句话，再刷新会话状态。
- **聊天登录失效**：进入聊天设置重新扫码。
- **服务号没有通知**：检查关注状态和 token，重新发送测试通知。
- **连接失败**：检查网络；启用了系统代理时，需保持代理程序运行。刚创建的云端网址可能需要几分钟生效。
- **本机网页连接断开**：重新运行 `打开网页版.cmd`，使用自动打开的新页面并关闭旧标签页。每次启动的本机地址可能不同；本机网页断开不影响云端监控。
- **接口已接受，但手机没收到**：接口接受不代表实际送达。分别测试通道，并检查微信免打扰、系统通知权限及锁屏设置。

每个通道每分钟最多发送一次测试通知。声音、未读标记和锁屏效果以手机实际测试为准。

## 技术说明

- **数据**：每两分钟读取社区站 [codex-reset.com](https://codex-reset.com/developers/) 的公开数据，并非直接连接 X，可能存在采集和推送延迟。消息时间显示为北京时间，原文的 today / tomorrow 按作者当地语境理解。
- **运行**：Cloudflare Workers 执行定时监控，SQLite Durable Objects 保存状态、去重记录和待发消息。无需常开服务器。平台额度与费用见 [Cloudflare 官方说明](https://developers.cloudflare.com/durable-objects/platform/pricing/)，推送服务限制见各供应商官网。
- **管理**：本机使用 Node.js；网页仅监听 `127.0.0.1`，与终端共用管理流程和配置。管理凭据由当前 Windows 账号加密保存，云端接口使用管理密钥认证。
- **推送**：服务号通过虾推啥或 pushplus 发送，聊天通过微信 iLink 接入；两个通道分别记录结果并重试。网络异常可能导致延迟、重复或无法送达。

工具监测公开公告，不查询你的个人 GPT 账号额度。「暂未发现新消息」不代表今天不会重置；收到完成消息后，账号是否到账仍需查看额度页面。

请勿共享 `.tibo-local` 文件夹、管理密钥或推送 token。安全说明见 [SECURITY.md](SECURITY.md)，素材许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
