# GPT今天重置了吗？

在电脑上查看 Tibo（[@thsottiaux](https://x.com/thsottiaux)）的重置预告、发放进度和完成消息，也可以在手机微信接收提醒。当前关注 **Codex / ChatGPT Work 的公开额度重置公告**。

**[下载最新版 ZIP](https://github.com/wmxxhb/did-gpt-reset-today/archive/refs/heads/main.zip)** → 完整解压 → 双击 `打开网页版.cmd` 或 `打开工具.cmd`。

通过 Windows 中文向导部署到 Cloudflare。网页采用 macOS 风格，终端入口继续保留；两种入口使用相同的配置和功能。开通后电脑关机仍会监控；无需购买域名或常开服务器。

## 网页与终端入口

| 入口 | 使用方式 |
| --- | --- |
| `打开网页版.cmd` | 自动在浏览器打开本机管理页，适合日常使用 |
| `打开工具.cmd` | 原终端中文菜单，继续可用 |

网页版提供概览、最近动态、通知设置和更多四个页面。可完成首次开通、连接已有工具、恢复管理权限、服务号绑定、微信聊天扫码、独立开关、测试及手机确认、提醒范围、暂停恢复、继续开通、更新和诊断，与终端共用同一套操作流程。

网页从本机 `127.0.0.1` 打开，自动读取当前目录的加密配置，不需要再次填写已有密钥。请保留后台启动窗口；关闭窗口后管理网页将断开，云端监控不受影响。网页刷新可以继续当前操作。更新本机文件后，需要关闭网页和后台窗口，再重新打开。

首次 Cloudflare 授权会另开官方页面。若需注册 workers.dev 免费网址，按网页提示打开 Cloudflare 开通页面，完成后点击继续即可；不需要回到终端输入英文选项。服务号 token、管理密钥和配对数字在网页中隐藏输入。扫码二维码在本机生成，不经过第三方图片服务。

网页不需要新增托管服务或付费组件。图标使用本地打包的 Lucide SVG，许可及界面参考见 [第三方素材说明](THIRD_PARTY_NOTICES.md)。

## 第一次使用

需要 Windows、Node.js 22+ 和一个 [Cloudflare 账号](https://dash.cloudflare.com/)。入口会检查运行组件，缺少 Node.js 时提供官方下载入口；已有 Codex 的机器也会尝试使用自带的 Node。

1. 双击 `打开网页版.cmd` 或 `打开工具.cmd`，选择「第一次使用，开始设置」。
2. 选择通知方式，只需配置你选中的通道。
3. 按向导登录 Cloudflare，完成云端开通、绑定及测试。网页版会在页面内显示每一步和等待进度。

| 通知方式 | 如何绑定 | 使用特点 |
| --- | --- | --- |
| 服务号 | 关注[虾推啥](https://xtuis.cn/)获取 token；也兼容已有 pushplus | 维护操作少，微信可能折叠通知 |
| 聊天提醒 | 用接收通知的微信扫描 ClawBot 二维码，再主动发一句话 | 在聊天会话接收，需要定期回复续期 |
| 两种都开启 | 分别绑定 | 同时发送，可能收到两份提醒 |
| 先只看动态 | 不绑定通知通道 | 仍会更新动态，不发送通知 |

默认提醒「预告 + 完成」，可储备重置默认关闭；可以稍后在「更多 → 提醒内容」中修改。服务号和聊天通道可随时独立开关，关闭一个不影响另一个。关闭后保留绑定，重新开启不会补发关闭期间的消息。

首次 Cloudflare 授权若出现免费网址的英文询问：创建选 `yes`，名称可填 `tibo-alert-加任意数字`，再确认 `yes`。完整工具网址由向导自动识别。

开通进度和管理凭据使用当前 Windows 账号加密保存。中断后可重新打开继续；「更多 → 继续开通」也能恢复。无需手动拼接测试网址或上传密钥。

## 打开后怎么看

首页自动显示最新重置动态、发布时间、原帖、最近更新时间及两个通道的可用情况。有异常时会提示下一步操作。

- **查看最近动态**：查看最近识别的消息，以及服务号、聊天通道各自的处理结果。
- **通知设置**：分别管理服务号和聊天提醒的绑定、开关和测试。
- **发送测试通知**：选择已开启的通道，逐个确认手机是否收到。
- **暂停 / 恢复通知**：暂停时继续更新动态，停止发送并清空待发通知；恢复后不补发暂停期间的消息。
- **更多**：提醒内容、更新、连接已有工具、恢复管理权限和诊断信息。

「暂未发现新的重置消息」不代表今天不会重置。数据异常时显示「暂时无法确认最新情况」，并保留历史动态的发布时间。Tibo 的完成声明与第三方监测记录使用不同标题；工具不会查询你的个人 GPT 账号额度。

## 微信聊天提醒（ClawBot）

在「通知设置 → 聊天提醒」中扫码开启。用接收通知的手机微信确认授权；出现配对数字时，按向导输入。绑定后在 ClawBot 会话里先发一句话，再验证测试消息的声音、锁屏提示及未读标记。

这是基于微信 iLink 的实验性通道，**最后一次用户消息之后约 24 小时、连续约 10 条消息后，需要你再回复一句话**。无需备用微信号，也不需要电脑常开。

工具约每两分钟同步回复；恢复后最多发送一次简短确认。也可以从聊天设置手动刷新。测试、恢复确认及可能已经送达的超时请求都计入本工具的保守额度估计，微信的实际限制为准。机器人自行发消息不会延长会话。

- 聊天消息最多等待一小时，过期不再补发；最近动态会说明已过期或等待恢复。
- 仅开启聊天通道且会话过期时，会明确提示当前无可用通知通道，不会自动开启服务号。
- 「暂时关闭」保留绑定；「清除聊天绑定」删除本工具存储中的凭据和队列。
- 消息是否显示数字角标、声音及锁屏提示，以微信版本、系统权限和手机实际测试为准。

实现参考：[腾讯 iLink 项目](https://github.com/Tencent/openclaw-weixin)、[Cloudflare 通知桥接方案](https://github.com/krapnikkk/Cloudflare-WeChat-Notifier)、[会话限制说明](https://github.com/yuuouu/WeChat-Bridge#微信侧限制)。本工具直接接入 iLink，不需要另购托管桥接或 AI API 服务。

## 没有收到提醒时

先看首页需要处理的事项，再在「发送测试通知」中测试对应通道。

- 聊天提示续期：在微信给 ClawBot 回复一句话，约两分钟内自动恢复，也可手动刷新。
- 聊天提示重新登录：进入「通知设置 → 聊天提醒」重新扫码。
- 服务号异常：检查公众号关注状态和绑定 token，再重试测试。
- 没看到新的重置消息：查看最近动态，区分没有新消息、提醒范围未选中、通知关闭、已暂停或发送失败。

接口返回「已接受」不等于手机送达。服务号和聊天分别确认，收到一边不会自动把另一边标成成功。每个通道每分钟最多测试一次；尚未开启的通道不需要测试。

Windows 联网沿用系统代理及证书配置。若启用了系统代理，请保持代理程序运行。联网、授权、部署等等待过程会显示动态标识和时间；网络失败可以重试。

## 更新与连接已有工具

当前版本：**0.3.0**。

在「更多 → 检查更新」中查看本机、云端和 GitHub 公开版本。发现新版时，可先更新本机，重新打开入口后再从同一入口更新云端。更新保留 `.tibo-local` 配置、已有绑定和提醒偏好；Git 仓库有未提交源码修改时，会提示手动处理。

早期版本首次升级：

1. Git 用户在原仓库执行 `git pull --ff-only`；ZIP 用户下载最新版，完整解压后覆盖原源码，**保留原 `.tibo-local` 目录**。
2. 关闭旧窗口，重新双击 `打开工具.cmd`，按提示准备运行组件。
3. 选择「更多 → 检查更新 → 更新云端程序」。

旧版本的云端更新入口不会下载新版的本机菜单。换电脑或没有本机连接配置时，从欢迎菜单选择「连接已有工具」，输入原网址和管理密钥。找不到密钥可选择「恢复管理权限」；它会生成新密钥并使旧密钥失效，已有云端绑定和记录保留。

## 数据与运行说明

每两分钟读取一次独立社区站 [codex-reset.com](https://codex-reset.com/developers/) 的公开数据，并非直接连接 X，可能有采集、检查和推送延迟。显示的消息时间为北京时间；原文的 today/tomorrow 仍按作者当地语境理解。

首次启动静默建立基线，历史消息可查看但不补发。之后处理最近 72 小时内的新事件，同一事件从预告变成完成可再次提醒。服务号与聊天分别记录发送结果和重试；失败不会使另一通道已成功的通知重发。网络超时或异常中断仍可能造成重复，无法保证每条送达。

服务号与聊天可以都关闭，此时仅查看动态。暂停通知也不会停止数据更新。关闭工具窗口或电脑不影响云端运行。

Cloudflare 使用 SQLite Durable Objects，可在免费计划的额度内运行；额度和价格以[官方说明](https://developers.cloudflare.com/durable-objects/platform/pricing/)为准。服务号供应商也有各自限制，具体规则见其官网。iLink 的通道能力和可用性可能变化。

## 开发与发布

```powershell
npm ci
npm test
npm run check:public
npm run manage
npm run web
npm run preview
npm run dev
```

开发使用 Node.js 22+；预览不发微信消息。配置示例见 `.dev.vars.example`。公开发布前先暂存文件，再执行 `npm run check:public`；GitHub Actions 在 Windows 和 Linux 上运行测试及公开文件检查，不部署用户实例或发送通知。

管理 API 均需 `Authorization: Bearer 管理密钥`：`/status`、`/settings`、`/channels` 读取状态和设置；`/check`、`/test`、`/pause`、`/resume` 及测试确认接口用于管理。聊天使用 `/clawbot/` 下的状态、扫码、刷新、测试、开关和清除接口。内部队列与投递接口不对外开放。

部署服务名由 `wrangler.jsonc` 中的 `tibo-wechat-reset-alert` 指定，升级已有实例时保持不变。新功能保留旧实例的已开启通道和提醒偏好。

源码不包含真实凭据或运行状态。管理凭据保存在 `.tibo-local`，请勿共享；分发请使用仓库链接或源码 ZIP。更多说明见 [SECURITY.md](SECURITY.md)。

该工具与 OpenAI、Tibo、腾讯及数据站均无隶属关系。
